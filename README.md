# MSPM0 移动测温回收机器人

基于 TI MSPM0G3507 的四轮移动机器人固件与载板设计资料。项目面向移动测温、房间巡检和物品回收任务，包含循迹导航、航向闭环、红外测温、语音提示、无线回传、LCD 显示及 PCB 载板设计。

## 主要功能

- 使用 AuroraT8 灰度传感器完成循迹、路口和支路识别。
- 基于路线表的任务状态机，支持房间停靠、回程、充电区和停车场流程。
- 使用 MLX90614 完成非接触体温测量，采用 PB17/PB18 软件 I2C。
- 使用 UART IMU 完成原地转向和航向闭环。
- 使用 ESP32-S2 授时模块获取日期和时间。
- 使用 ASRPRO2.0 播放房间与任务语音提示。
- 使用 LoRa 回传测量结果和设备状态。
- 使用 ST7735S LCD 显示任务状态、温度、电量及调试信息。
- 提供 MSPM0G3507 载板的 KiCad 原理图、立创 EDA 工程、BOM、网表和接线文档。

## 构建

1. 安装 TI MSPM0 SDK 2.02.00.05 和 Keil MDK，并安装 MSPM0G350x 器件支持包。
2. 使用 Keil 打开 `keil/empty_LP_MSPM0G3507_nortos_keil.uvprojx`。
3. 选择与实物一致的下载器和调试配置，编译并下载固件。
4. 修改外设配置时使用 `empty.syscfg`，并确保生成的 `ti_msp_dl_config.c/.h` 与工程同步。

仓库不包含 Keil 编译产物和用户界面状态文件。`.gitattributes` 保留现有源码的编码与换行方式，避免无意义的整文件差异。

## 调试说明

- LoRa UART3 作为主要运行日志输出口。
- `middle/Mission.c` 中的 `route[]` 表定义任务路线和动作顺序。
- 循迹、转向、测温与语音模块均保留现场调试参数，调整前应先确认对应引脚和电源连接。
- 载板设计文件位于 `pcb/`；重新生成前请阅读生成脚本和验证报告。
